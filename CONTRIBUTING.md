## 🇧🇷 Português

Obrigado por se interessar em contribuir para o **Poke-README**! 🎉

Como este é um projeto open-source, toda ajuda é super bem-vinda: sejam correções de bugs, features novas, novos sprites, melhorias no código ou até mesmo na documentação.

### 🛠️ Como contribuir

1. **Faça um Fork** deste repositório.
2. Crie uma **Branch** com a sua feature ou correção:
   `git checkout -b feature/minha-feature-incrivel`
3. **Faça o Commit** das suas alterações com uma mensagem clara sobre o que foi feito.
   `git commit -m "feat: adiciona novos sprites de pokemons da 5ª geração"`
4. Faça o **Push** para a sua branch:
   `git push origin feature/minha-feature-incrivel`
5. Abra um **Pull Request** no repositório original.

### 📝 Regras para o Pull Request

- Descreva detalhadamente o que o PR altera ou adiciona.
- Se for uma mudança visual, tente adicionar um screenshot/print mostrando a alteração.
- Mantenha o código limpo, comentado (quando necessário) e respeitando a padronização já existente do projeto.
- O projeto usa **Husky** e **Prettier** para garantir a formatação. Seu código será formatado automaticamente ao fazer o commit.
- Não faça commit na branch `main` diretamente!

### 🧪 Rodando Localmente

Para testar suas atualizações na sua máquina:

1. Clone o seu fork (`git clone https://github.com/SEU_USER/Poke-README.git`)
2. Instale as dependências: `npm install`
3. Inicie o servidor de testes local: `npm run dev`
4. O servidor iniciará em `http://localhost:3000` onde você poderá acessar a API.

Obrigado novamente por tornar o Poke-README melhor!

## 🇺🇸 English

Thank you for your interest in contributing to **Poke-README**! 🎉

As this is an open-source project, all help is super welcome: bug fixes, new features, new sprites, code improvements or even documentation updates.

### 🛠️ How to contribute

1. **Fork** this repository.
2. Create a **Branch** with your feature or fix:
   `git checkout -b feature/my-awesome-feature`
3. **Commit** your changes with a clear message about what was done.
   `git commit -m "feat: add new 5th gen pokemon sprites"`
4. **Push** to your branch:
   `git push origin feature/my-awesome-feature`
5. Open a **Pull Request** in the original repository.

### 📝 Pull Request Rules

- Describe in detail what the PR changes or adds.
- If it's a visual change, try to add a screenshot showing the change.
- Keep the code clean, commented (when necessary) and respecting the existing project standards.
- The project uses **Husky** and **Prettier** to ensure formatting. Your code will be automatically formatted when you commit.
- Do not commit directly to the `main` branch!

### 🧪 Running Locally

To test your updates on your machine:

1. Clone your fork (`git clone https://github.com/YOUR_USER/Poke-README.git`)
2. Install dependencies: `npm install`
3. Start the local test server: `npm run dev`
4. The server will start at `http://localhost:3000` where you can test the API.

Thanks again for making Poke-README better!

## 🇪🇸 Español

¡Gracias por tu interés en contribuir a **Poke-README**! 🎉

Como este es un proyecto de código abierto, toda ayuda es súper bienvenida: correcciones de errores, nuevas funciones, nuevos sprites, mejoras de código o incluso actualizaciones de documentación.

### 🛠️ Cómo contribuir

1. Haz un **Fork** de este repositorio.
2. Crea una **Branch** (rama) con tu función o corrección:
   `git checkout -b feature/mi-increible-funcion`
3. Haz un **Commit** de tus cambios con un mensaje claro sobre lo que se hizo.
   `git commit -m "feat: agrega nuevos sprites de pokemon de la 5ta gen"`
4. Haz **Push** a tu rama:
   `git push origin feature/mi-increible-funcion`
5. Abre un **Pull Request** en el repositorio original.

### 📝 Reglas del Pull Request

- Describe en detalle qué cambia o añade el PR.
- Si es un cambio visual, intenta agregar una captura de pantalla que muestre el cambio.
- Mantén el código limpio, comentado (cuando sea necesario) y respetando los estándares del proyecto existentes.
- El proyecto utiliza **Husky** y **Prettier** para garantizar el formato. Tu código se formateará automáticamente al realizar el commit.
- ¡No hagas commit directamente en la rama `main`!

### 🧪 Ejecución Local

Para probar tus actualizaciones en tu máquina:

1. Clona tu fork (`git clone https://github.com/TU_USUARIO/Poke-README.git`)
2. Instala las dependencias: `npm install`
3. Inicia el servidor de prueba local: `npm run dev`
4. El servidor se iniciará en `http://localhost:3000` donde podrás probar la API.
